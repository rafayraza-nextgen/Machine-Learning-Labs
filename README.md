# Machine Learning Labs

This repository contains lab assignments and practical implementations for Machine Learning concepts, algorithms, and workflows using Python, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-Learn.

---

## 📚 Labs Overview

| Lab | Topic | Description & Algorithms | Dataset |
|:---:|:---|:---|:---|
| **Lab-1** | Data Preprocessing & EDA | Exploratory Data Analysis, missing value handling, feature scaling with `StandardScaler` | Titanic Dataset |
| **Lab-2** | Linear Regression | Implementation and evaluation of Linear Regression with visualizations | Diabetes Dataset |
| **Lab-3** | Classification & Logistic Regression | Binary classification, model evaluation metrics, and feature scaling | Breast Cancer Dataset |
| **Lab-4** | Decision Tree Classifier | Decision tree modeling, tree visualization, and performance assessment | Iris Dataset |
| **Lab-5** | Support Vector Machines (SVM) | SVM classification with linear and non-linear kernels | Breast Cancer Dataset |
| **Lab-6** | Hyperparameter Tuning & Grid Search | Optimizing model performance with `GridSearchCV` | Breast Cancer Dataset |
| **Lab-8** | K-Nearest Neighbors (KNN) | Instance-based learning, distance metrics, and K tuning | Iris Dataset |
| **Lab-9** | Naive Bayes Classifier | Probabilistic classification using Gaussian Naive Bayes (`GaussianNB`) | Iris Dataset |
| **Lab-10** | Unsupervised Learning & Clustering | K-Means clustering, Elbow method, and Silhouette score evaluation | Mall Customers Dataset |

---

## 🛠️ Tech Stack & Libraries

- **Python 3.x**
- **Jupyter Notebook**
- **NumPy** & **Pandas** (Data manipulation and analysis)
- **Matplotlib** & **Seaborn** (Data visualization)
- **Scikit-Learn** (Machine learning algorithms and preprocessing)

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rafayraza-nextgen/Machine-Learning-Labs.git
   cd Machine-Learning-Labs
   ```

2. **Install dependencies:**
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn notebook
   ```

3. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
